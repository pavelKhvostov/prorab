# TypeScript

- `strict: true`, `noUncheckedIndexedAccess: true`.
- Никаких `any`. Если действительно неизбежно — `unknown` + сужение.
- `@ts-ignore` / `@ts-expect-error` — только с комментарием почему и ссылкой на тикет/строку.
- Внешние данные (форма, fetch) проходят через Zod. Тип = `z.infer<typeof Schema>`, не пишем руками рядом со схемой.
- Имя файла = имя экспорта. Один компонент = один файл.
- Импорты сортированы: внешние → алиасы (`@/`) → относительные. Пустая строка между группами.
- Никаких `default export` для утилит/типов. Для страниц/компонентов Next — как требует фреймворк.
