# Доступность (a11y)

- Контраст AA минимум — проверяй по токенам, не по «выглядит норм».
- Видимый `:focus-visible` на всех интерактивных элементах. Не убирай outline без замены.
- Семантика: `<button>` для действий, `<a>` для навигации. Не клик-дивы.
- Формы: каждый инпут с `<label>` (или `aria-label`). Ошибки рядом с полем, плюс `aria-describedby`.
- Статус сабмита формы — `aria-live="polite"`. Спинер с `aria-label="Отправка…"`.
- Заголовки иерархично: один `<h1>` на страницу (в hero), дальше `<h2>` по секциям, `<h3>` внутри.
- Touch-таргеты ≥ 44×44 px на мобиле.
- Декоративные SVG — `aria-hidden="true"`. Информативные — с `<title>` или `aria-label`.
- Не полагайся только на цвет (ошибка ≠ красный без иконки/текста).
